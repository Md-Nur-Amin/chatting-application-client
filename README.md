# Chatting-Application Client

# 💬 React Realtime Chat Application

A modern, clean real-time chat application built with **React** and **Socket.IO**. Users can join chat rooms, send text and image messages, and use emoji reactions – all with a responsive, full-screen UI.

---

## 🚀 Features

- 🔒 Join private chat rooms
- 💬 Realtime messaging via Socket.IO
- 😀 Emoji picker integration
- 🖼️ Image upload support (Base64)
- 🎨 Clean, full-screen responsive UI using Tailwind CSS
- 🌐 Lightweight and scalable

---

---

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS
- **Realtime Communication**: Socket.IO
- **Icons**: React Icons
- **Emoji Support**: emoji-picker-react

## 🧑‍💻 Getting Started

### ⚙️ Prerequisites

Make sure you have the following installed:

- Node.js
- npm or yarn

Also, ensure that the **backend server** (Socket.IO) is running on `http://localhost:3001`

---

### 📦 Installation

1. **Clone the repository**:

```bash
git clone https://github.com/Md-Nur-Amin/chatting-application-client.git
cd react-socket-chat


Install dependencies:
npm install


Start the app:
npm start


The app should now be running on:
http://localhost:3000


⚙️ Environment & Backend
This app expects a backend Socket.IO server running on:
http://localhost:3001
